# 漢食（かんしょく）

調べてくれる相棒に、遊んでごちそう。
漢字を調べてくれる食いしん坊の相棒と暮らす、モバイルファーストのWebアプリ（MVP）です。

## 起動方法

Node.js 20 以上が必要です。

```bash
cd kanshoku
npm install
npm run dev
```

ブラウザで http://localhost:5173 を開きます。スマートフォンで確認するときは、同じWi-Fiにつないで、ターミナルに表示される `Network:` のURLを開きます（カメラを画面内で起動するには HTTPS か localhost が必要です。HTTPのLAN URLでは「撮影する」「写真をえらぶ」を使ってください）。

| コマンド | 内容 |
|---|---|
| `npm run dev` | 開発サーバー |
| `npm test` | 自動テスト（報酬の二重付与防止・食事の消費・保存の復元など） |
| `npm run build` | 本番用のファイルを `dist/` に作成 |
| `npm run preview` | 作成した `dist/` を確認 |
| `npm run art:rough` | 仮素材の SVG に手描きの揺れを焼き込み直す（scripts/art-src → public/assets） |

## できること

- **おへや**：相棒・部屋。上に検索の入口、右に模様替えとごはんのボタン。相棒のひとことは吹き出しを使わず 文字だけがポンと出て消える。相棒はタップで反応
- **ごはんかご**：部屋の下から開く引き出し（閉じるときは下へすべって消える）。選ぶと青い枠で囲まれ 手が相棒までドラッグして見せる → 「食べさせる」。相棒へのドラッグでも渡せる
- **模様替え**：持っている家具を選ぶと部屋に反映（固定スロット方式・6か所）。左上の「もどる」で変えたところを元に戻せる
- **プロフィール**：紙のカード風。名前の変更、出会った日、好きなごはん、食べた記録、設定
- **しらべる**：文字入力（変換確定と送信を区別）、同じ読みの候補、最近の履歴、カメラ（端末内OCR）、声（Web Speech API）
- **ことばの画面**：形・読み・短い意味 → 例文 → くわしく（画数・部首）。「大きく見る」、あつめた漢字に入れる（読み／書き／意味の複数タグ・あとで編集・保存解除）
- **あつめた漢字**（旧ことばポケット）：フィルター、検索、カード一覧（読み＝ミント・書き＝黄色・意味＝ピンク）、詳細へ、「このことばであそぶ」
- **あそぶ**：いちばん上で遊び方・難しさを変え、その下のおすすめをすぐ開始。1ラウンド3問・時間制限なし・難しさ3段階
  - **漢字を書く**（旧 仕上げのひと筆）：読みと文から漢字を手書き。消す・1画戻す・ヒント。見本は書く枠の右上の目のボタン。見本と自分の字を並べて**自分で**判定（自動判定なし。白紙では進めない。見本を見たら「練習」として記録）
  - **答えをえらぶ**（旧 ことばあわせ）：読み・文に合う意味を選ぶ。回答ごとに料理の材料（にんじん・トマト・ブロッコリー）がそろう。間違えても正しい内容を見せて続行
- **ごほうび**：毎ラウンド基本のごはんを必ず1つ。難しいほどおまけ（珍しいごはん）が出やすい。家具はときどき＋4回出なければ確実に1つ
- **食事の反応**：おにぎり（ほおばる＋ほっぺに海苔）／プリン（ぷるぷる）／スープ（ふうふう＋湯気）／おだんご・たいやき（跳ねて回る）／オムライス（じっくり味わう）
- **相棒のようす**：検索中のしぐさ、検索後の「ふう」、続けて調べると休憩（時間で回復）、空腹で「お皿を抱える → 冷蔵庫をのぞく → クッションでへにゃっ」（それ以上は進まない）。数値のゲージは表示しない
- **保存**：端末のブラウザ内（localStorage）。会員登録なし

## デモデータの範囲

- 収録語は **49語**（大学・バイト・仕事・くらし）。未収録の語には「見つからなかった」と表示し、関係のない結果は返しません
- 同じ読みの語の例：いどう（移動／異動）、いがい（以外／意外）
- 出典・確認方法は [docs/DATA_SOURCES.md](docs/DATA_SOURCES.md)

## 未実装・外部接続が必要なもの

- 外部の辞書（収録語以外の検索）：`src/dictionary/provider.ts` を差し替えて接続
- 書き順：確認済みのデータがないため未表示（データを追加すると「書き順を見る」が出ます）
- 手書きの自動判定：未実装（自己確認方式）
- 複数キャラの同時育成、家具の自由配置：拡張候補
- カメラのOCRは初回に約6MBを cdn.jsdelivr.net から取得します。オフラインの初回は使えません（エラー表示と代替手段あり）
- 音声入力は対応ブラウザ（Chrome・Safari など）のみ。Firefox などでは「非対応」と表示します

## 例外状態

初回の案内、保存なし、ごはんなし、検索結果なし、読み込み中、通信エラー、カメラ・マイクの権限拒否、機能非対応、遊びの中断（あとでつづきから）、保存データの破損（自動で退避して新しく開始）、ブラウザの保存が使えない、画像の読み込み失敗。

開発時は、URLに `?debug=dict-error` を付けると辞書の通信エラー表示を確認できます（例：`http://localhost:5173/?debug=dict-error#/search?q=目標`）。

## イラストの差し替え

- 設定ファイル：`src/config/assets.config.ts`（ここだけで差し替え）
- 画像の置き場所：`public/assets/`
- 手順書：[docs/ASSETS_GUIDE.md](docs/ASSETS_GUIDE.md)
- 確率・時間などの調整：`src/config/game.config.ts`

## ファイル構成

```
src/
  config/      assets.config.ts（絵の設定）・game.config.ts（確率や時間）
  data/        catalog.ts（ごはん・家具のID）・words.ts（収録語）
  dictionary/  検索の窓口
  store/       状態・保存・復元
  game/        出題・報酬・相棒のようす
  art/         絵の表示（部屋・相棒・画像の代替表示）
  screens/     各画面
  ui/          共通部品・手書き欄
  styles/      デザイントークン・各画面のスタイル
docs/          差し替え手順書・出典・Figmaとの対応
public/assets/ 仮素材のイラスト
```
