# データ・素材の出典とライセンス

## 漢字データ（`src/data/words.ts`）

デモ用に、大学・バイト・仕事・くらしの場面でよく使う **49語** を収録しています。外部の辞書には接続していません。

| 項目 | 内容 | 確認方法 |
|---|---|---|
| 見出し語・読み | 一般的な国語辞典の見出しと同じ表記・読み | 国語辞典（例：『大辞林』『明鏡国語辞典』など）の見出しで確認できます |
| 意味 | このアプリのために書き下ろした短い要約。辞書の本文は転載していません | 上記の辞書の語義と照らし合わせて確認できます |
| 例文 | このアプリのための作例（大学生活・バイト・仕事を想定） | — |
| 読みまちがいの選択肢 | よくある誤読（例：雰囲気→ふいんき）。出題の選択肢にだけ使います | — |
| 画数・部首 | Unicode Unihan データベースの `kTotalStrokes`（画数）と `kRSUnicode`（部首）で照合できる値。部首の分類が辞書によって分かれる字（「当」）は空欄にしています | https://www.unicode.org/charts/unihan.html |
| 書き順 | **未収録**。根拠のある書き順データがないため、「書き順を見る」ボタンは表示していません | — |

**注意**：データは制作者（AIを含む）が手作業で入力したものです。自動での全件照合はしていません。公開前に、国語辞典と Unihan で目視確認することをおすすめします。データの形式チェック（例文に見出し語が入っているか、読みがひらがなか、すべての漢字に画数があるか）は自動テストで確認しています。

### 書き順データを追加する場合

確認済みの書き順画像（例：KanjiVG — CC BY-SA 3.0 — から作った画像）を `public/strokes/` に置き、該当する語の `strokeOrder` に画像のパスを書くと、結果画面に「書き順を見る」が表示されます。ライセンス表記の追加が必要です。

### 将来の辞書接続

検索は `src/dictionary/provider.ts` の `DictionaryProvider` を通しています。外部の辞書APIに接続するときは、この部分を差し替えます（画面側の変更は不要です）。

## 文字の読み取り（カメラ）

- ライブラリ：tesseract.js（Apache License 2.0）
- 日本語データ：tessdata（Apache License 2.0）。初回に cdn.jsdelivr.net から取得します（約6MB）
- 画像は端末内で処理し、外部へ送信しません

## 音声入力

- ブラウザ標準の Web Speech API（SpeechRecognition）を使います
- Google Chrome などでは、音声がブラウザの提供元のサーバーに送られて文字になります。アプリ側では音声を保存・送信しません

## フォント

- LINE Seed JP（SIL Open Font License 1.1）— すべての文字（見出し・本文・ボタン・漢字の見本）
- Google Fonts から読み込みます。読み込めない場合は端末の日本語フォントで表示します

## アイコン

- Flowbite Icons（MIT License・https://github.com/themesberg/flowbite-icons）の solid 版を `src/ui/icons.ts` に収録
- 「とじる」の×だけは Flowbite の x-solid が X（旧Twitter）のロゴのため 自作の形
- 入力欄の中の虫めがねだけ Flowbite の search-outline

## イラスト

- `public/assets/` の画像は、すべてこのMVPのために作った仮素材（SVG図形）です
- 参考画像に含まれるキャラクター・ロゴ・文章は使用していません
