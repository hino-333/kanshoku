# 既存Figmaプロトタイプとの対応

確認した資料：https://www.figma.com/design/xOu6uGmIi9gBIe1hX6OzsE/ （Page 1 のスマホ画面18枚）

## 確認できなかったこと

- **Page 2**：取得時にエラーになり、内容を確認できていません。
- **プロトタイプのリンク設定（どのボタンがどの画面へ遷移するか）**：ツールで読み出せなかったため、下の遷移は画面の並び・戻る矢印・ボタンの文言からの**推定**です。

## 画面の対応

| 元の画面（Figma） | 改善後 | 残した点 | 変えた点 |
|---|---|---|---|
| スプラッシュ（KANSHOKU ロゴ） | 初回の短い案内（3枚・スキップ可） | ロゴ「漢食」の世界観 | 待ち時間をなくし、名前付けと最初のごはんを案内 |
| ホーム（猫・おでぶちゃん度ゲージ・「漢字一筋」・下部3ボタン） | おへや | 猫が主役の画面構成、下からの導線 | ゲージを廃止し、表情・しぐさ・小物で状態を表現。上に検索の入口 |
| 下部ナビ（いぶくろ／調べる／ダイエット） | おへや／しらべる／あそぶ／ポケット | 3つの入口 | ホームを明示する「おへや」を追加。現在地を背景と形で表示 |
| 調べる（文字入力・カメラ検索・音声検索） | しらべる | 3つの入口、文字入力を最上段に | 最近の履歴、デモ範囲の表示、変換確定と送信の区別 |
| カメラ検索（枠に写す・シャッター） | カメラで調べる | 枠付きのファインダー | 画像選択・撮影アプリ、読み取り結果の修正、権限拒否時の代替 |
| 音声検索（話してください・波形） | 声で調べる | 波形の表示 | 聞き取り結果の確認・修正、非対応・権限拒否の表示 |
| 結果（燐：画数・部首・音訓・意味・熟語、保存ボタン） | ことばの画面 | 「保存」を主要操作に、画数・部首 | 形・読み・短い意味を最上部に。例文を追加し、詳細は折りたたみ |
| 保存先の選択（読み／書き／意味・新規いぶくろ） | タグ選択パネル | 読み／書き／意味の3分類 | 複数選択に。フォルダ作成は廃止。保存後は結果画面に戻る |
| 保存しました（おでぶちゃん度上昇） | 「ポケットにしまった」 | 保存の完了を伝える | 不利益をなくし、カードがポケットに収まる動きに |
| いぶくろ一覧（読み／書き／意味） → カード一覧 → 展開 | ことばポケット | 3分類とカード形式 | フィルター・検索・タグ編集・「このことばであそぶ」 |
| ダイエット（3コース・消費おでぶちゃん度） | あそぶ | 3段階の難しさ | おすすめをすぐ始められる構成。報酬はごはん |
| クイズ形式（読み／書き） | ことばあわせ／仕上げのひと筆 | 読みと書きの2系統 | 選択式の読み・意味／手書きと見本の見くらべ |
| 読みクイズ（ルビ＋入力）・書きクイズ（十字ガイドの手書き枠） | 各問題画面 | 十字ガイドの大きな手書き枠 | 自動で正解にしない自己確認方式。回答ごとに料理が進む |
| 大正解！次へ → ダイエット成功！ホームへ | フィードバック → できあがり → 食べさせる | 下からの結果パネル | 点数ではなく、料理と相棒の反応を主役に |
| 満タンです（警告） | 廃止 | — | 罪悪感・義務感を与える表現をなくす |

## 推定した遷移

```
スプラッシュ → ホーム
ホーム ─ 調べる → 文字入力 → 結果 → 保存先の選択 → 保存しました → ホーム
       │        ├ カメラ検索
       │        └ 音声検索
       ├ いぶくろ → 一覧 → 展開（詳細）
       └ ダイエット → コース選択 → 形式選択 → 問題×5 → 成功 → ホーム
```

改善後は、問題を5問から3問に短くし、保存後はホームではなく元の結果画面に戻るようにしました。
