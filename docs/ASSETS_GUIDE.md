# 漢食 イラスト差し替え手順書

このアプリの絵は、いまはすべて**仮素材**（かんたんなSVG）です。
あとから描いた絵に置きかえるときは、この手順書のとおりに進めてください。
プログラムの画面部分や、ごはん・家具の数を数える処理をさわる必要はありません。

---

## 1. しくみ（3行で）

1. 絵のファイルは `public/assets/` の中にあります。
2. 「どの絵を、どこに、どの大きさで使うか」は、**`src/config/assets.config.ts` の1つのファイル**にまとめて書いてあります。
3. 絵を変えるには、**同じ名前のファイルで上書きする**か、設定ファイルの `src`（画像の場所）を書きかえます。

ごはんや家具の「所持数」「食べた記録」「名前」は、画像のファイル名とは別のID（例：`onigiri`）で保存しています。
絵を差し替えても、記録が消えたり数が変わったりすることはありません。

---

## 2. まずはここから：最初に描くとよい素材

全部の差分を最初から描く必要はありません。下の順番で、1枚ずつ置きかえていけば十分です。

| 順番 | 素材 | 理由 |
|---|---|---|
| 1 | 相棒の通常の絵（`pet.base`） | すべての状態で使われます。これ1枚で、タップ・食事・休憩などの動きが全部つきます |
| 2 | 部屋の背景（`room.background`） | 画面の印象がいちばん大きく変わります |
| 3 | おにぎり・プリン・スープ（`food.onigiri` など） | 最初に手に入るごはん。食べ方の演出がそれぞれ違います |
| 4 | 最初からある家具4つ（まど・木のたな・まるいラグ・バタークッション） | 初回から部屋に置かれています |
| 5 | 下のナビのアイコン4つ（`icons.navRoom` など） | どの画面でも目に入ります |

そのあと、余裕があれば「任意の差分」（後述）を増やしていきます。

---

## 3. いちばんかんたんな方法：同じ名前で上書きする

例：相棒の通常の絵を差し替える

1. 描いた絵を、背景が透明な PNG で書き出します（例：横 960 × 縦 840 ピクセル）。
2. ファイル名を `normal.png` にします。
3. `public/assets/character/` フォルダに入れます。
4. `src/config/assets.config.ts` を開き、次の1行を探します。

   ```ts
   base: { src: A + 'character/normal.svg', aspect: 240 / 210, pivotX: 0.5, pivotY: 1, alt: '相棒のねこ' },
   ```

5. `normal.svg` を `normal.png` に、`240 / 210` を **あなたの絵の「横 / 縦」** に書きかえます。

   ```ts
   base: { src: A + 'character/normal.png', aspect: 960 / 840, pivotX: 0.5, pivotY: 1, alt: '相棒のねこ' },
   ```

6. 保存します。開発サーバーが動いていれば、ブラウザが自動で更新されます（動いていなければ「起動方法」を参照）。

> **SVGのまま差し替える場合**は、`public/assets/character/normal.svg` を同じ名前で上書きするだけで反映されます（設定ファイルの変更は不要。ただし縦横比が変わる場合は `aspect` も直してください）。

### 例：おにぎりを差し替える

1. 透明背景の PNG（例：512 × 512）を `public/assets/food/onigiri.png` として保存します。
2. 設定ファイルの次の行を書きかえます。

   ```ts
   onigiri: { src: A + 'food/onigiri.svg', aspect: 1, alt: 'おにぎり' },
   ```
   ↓
   ```ts
   onigiri: { src: A + 'food/onigiri.png', aspect: 1, alt: 'おにぎり' },
   ```

3. 保存してブラウザを確認します。ごはんかご・報酬画面・食事の演出のすべてに反映されます。

### 差し替え後の確認ポイント

- おへやで相棒をタップすると、弾む・傾くなどの反応があるか
- ごはんかごでごはんを選ぶと、相棒がそちらへ傾くか
- 「食べさせる」で食べる演出が出て、ごはんの数が1つ減るか
- プロフィールの名前や、ごはんの数が変わっていないか
- 縦横比が違う絵でも、ボタンや画面がはみ出していないか

## 4. 設定ファイルで使える値

`src/config/assets.config.ts` の各項目には、次の値を書けます。省略した値は初期値になります。

| 値 | 意味 | 例・初期値 |
|---|---|---|
| `src` | 画像の場所（`public/` から見たパス）。PNG・WebP・SVG | `A + 'food/onigiri.png'` |
| `aspect` | 画像の **横 ÷ 縦**。表示枠の形になります | `960 / 840`（初期値 1） |
| `scale` | 枠の中での大きさ。1 = 枠いっぱい | `0.9` で少し小さく |
| `offsetX` | 横位置の微調整（枠の幅に対する %。プラスで右へ） | `-3` |
| `offsetY` | 縦位置の微調整（枠の高さに対する %。プラスで下へ） | `2` |
| `pivotX` / `pivotY` | 動きの支点。0〜1。`pivotY: 1` は足元 | 相棒は `0.5, 1` |
| `alt` | 画面の読み上げに使う短い説明 | `'相棒のねこ'` |

**絵は枠の中に「縦横比を保ったまま、下ぞろえ」で収まります。** 切り抜かれたり、引き伸ばされたりはしません。画像の実際のピクセル数が大きくても、画面のレイアウトは広がりません。

## 5. 素材一覧

「必須」は、いま画面で使われている素材です（差し替えなくても仮素材で動きます）。
「任意」は、用意したときだけ使われる素材です。用意しなければ、通常の絵＋動きで表現します。

### 5-1. 相棒

| 用途 | 設定キー | 今の保存場所 | 推奨サイズ・縦横比 | 透過 | 区分 |
|---|---|---|---|---|---|
| 通常 | `pet.base` | `character/normal.svg` | 960×840（8:7）前後。縦長・横長でもOK（`aspect` を合わせる） | 必要 | **必須** |
| まばたき | `pet.states.blink` | `character/blink.svg` | base と同じキャンバス | 必要 | 任意（仮素材あり） |
| タップへの反応 | `pet.states.tap` | — | 同上 | 必要 | 任意 |
| ごはんを選んだとき | `pet.states.lean` | — | 同上 | 必要 | 任意（振り向き・視線の差分に） |
| 検索のお手伝い | `pet.states.search` | — | 同上 | 必要 | 任意 |
| ひと息（ふう） | `pet.states.sigh` | — | 同上 | 必要 | 任意 |
| 小腹が空いた（お皿を抱える） | `pet.states.peckish` | — | 同上 | 必要 | 任意 |
| 冷蔵庫をのぞく | `pet.states.hungry` | — | 同上 | 必要 | 任意 |
| クッションでへにゃっと | `pet.states.flop` | — | 同上 | 必要 | 任意 |
| 休憩 | `pet.states.rest` | — | 同上 | 必要 | 任意 |
| 食事中 | `pet.states.eating` | — | 同上 | 必要 | 任意 |
| ごきげん | `pet.states.happy` | — | 同上 | 必要 | 任意 |
| ごはん別の食べ方 | `pet.eatingByFood.onigiri` など | — | 同上 | 必要 | 任意（例：おにぎりを両手で抱える） |
| ほっぺに付くもの | `foodCheek.onigiri` | `deco/nori.svg` | 128×128 | 必要 | 任意（いまは海苔だけ） |

**相棒の絵の描き方のルール**

- **足元を画像の下端にそろえる。** 下の余白は 0〜2% 程度。状態を切りかえても位置が跳ねなくなります。
- **差分はすべて base と同じキャンバスサイズ・同じ位置で描く。** 体の中心と足元の位置をそろえてください。
- 左右と上の余白は 5% 程度あけると、弾む動きで切れません。
- 文字（吹き出しの中身など）は絵に入れないでください。吹き出しは画面側で表示します。
- アプリ全体は**輪郭線を使わないフラットなデザイン**です。絵のルール（チープに見せないための約束）：
  - 1つの絵に使う色は **2色＋文字色 #4B4038 まで**
  - 形は基本図形の組み合わせ。影・ハイライト・細かい模様は描かない
  - 相棒は1つの形を1色（いまは #FFD54F）で。目は体の幅の20%以上にして 目と口だけで表情を作る
  - 部屋の壁（淡い水色）と床（ベージュ）に対して はっきり区別できる明るさにする
- 差分の設定は、ファイルを置いてから、設定ファイルの `states:` の中の `//`（コメント）を外すだけです。

  ```ts
  // happy:   { src: A + 'character/happy.png',   aspect: 240 / 210 },
  ```
  ↓
  ```ts
  happy:   { src: A + 'character/happy.png',   aspect: 960 / 840 },
  ```

- **base の絵を差し替えたら、仮素材の `blink`（まばたき）も描きかえるか、行の先頭に `//` を付けて止めてください。** そのままだと、まばたきの瞬間だけ仮のねこが出ます。

### 5-6. アイコン（イラストではなく 1つのアイコンセットで管理）

アイコンは絵の差し替えの対象から外し、**Flowbite Icons（塗りの solid 版・MIT License）** に統一しました。
設定は `src/ui/icons.ts` の1ファイルだけです。

- 1つの意味に1つのアイコン（例：ごはん＝`bowl-food` を ナビ以外のすべての「ごはん」で使う）
- 色は1色。押せる所や現在地は主色 #38AACF、それ以外は文字色 #4B4038。ただし「ごはん」のアイコンは青と合わないので暖色 #E8735A
- 新しいアイコンが必要なときは 同じ Flowbite の solid 版から選ぶ（別のアイコンセットは混ぜない）
- 例外：入力欄の中の虫めがねだけは 塗りだとぼってり見えるので outline 版（`searchLine`）

| おへや | room | home-solid |
| しらべる | search | search-solid |
| 入力欄の虫めがね | searchLine | search-outline |
| あそぶ | play | shapes-solid |

### 5-7. 差し替え不要な部分

戻る・閉じる・チェックなどの小さな操作アイコン（線画）と、ボタンの文字・漢字の見本・所持数・入力欄は、絵ではなく画面の部品として作っています。描き直す必要はありません。

## 6. 部屋の配置を調整する（`layout`）

部屋は **横3：縦4** の舞台で、数値はすべて舞台に対する % です。

```ts
slots: {
  window: { x: 30, bottom: 55, width: 38, z: 1 },
  ...
},
pet: {
  default: { x: 54, bottom: 14, width: 40, z: 5 },  // ふだんの立ち位置
  fridge:  { x: 36, bottom: 22, width: 36, z: 5 },  // 冷蔵庫をのぞくとき
  cushion: { x: 24, bottom: 15, width: 38, z: 5 },  // 休憩・へにゃっとのとき
},
```

| 値 | 意味 |
|---|---|
| `x` | 絵の**中心**の横位置（左端 0 〜 右端 100） |
| `bottom` | 絵の**下端**の高さ（床 0 〜 天井 100） |
| `width` | 絵の幅（舞台の幅に対する %） |
| `z` | 重なり順。大きいほど手前 |

そのほかの値：`eatingFood`（食べているごはんの位置）、`plate`（お皿）、`fridge`（冷蔵庫）、`cheek`（ほっぺのシールの位置。相棒の枠に対する %）。

## 7. うまく表示されないとき

| 症状 | 確認すること |
|---|---|
| 「？」の点線の枠が出る | ファイル名・フォルダ名・拡張子（`.png` と `.PNG` の違いも）が設定と合っているか |
| 絵がつぶれて見える・小さすぎる | `aspect` が実際の画像の「横 ÷ 縦」になっているか |
| 状態を切りかえると位置がずれる | 差分の絵が base と同じキャンバスで、足元が下端にそろっているか |
| 絵の周りに白い四角が出る | 背景が透明な PNG / WebP で書き出しているか |
| 反映されない | ファイルを保存したか。ブラウザを再読み込みしたか |

読み込みに失敗しても、アプリは止まりません。相棒の差分が読めないときは通常の絵、それも読めないときは「？」の枠を出して、操作はそのまま続けられます。

## 8. ごはんや家具の「種類」を増やすとき（少しだけプログラムの変更が必要）

絵の差し替えは設定ファイルだけで済みますが、**新しい種類を増やす**ときは、ゲームのデータにも1行ずつ追加します。

1. `src/data/catalog.ts` の `FOOD_IDS`（家具は `FURNITURE_IDS`）にIDを追加し、`FOODS`（家具は `FURNITURE`）に名前や食べ方を追加します。
2. `src/config/assets.config.ts` の `food`（家具は `furniture`）に、同じIDで絵の設定を追加します。
3. 出る確率は `src/config/game.config.ts` で調整します。

## 9. 動作確認に使ったサンプル

`public/assets-alt/` に、差し替えの確認に使った画像があります。

- `character/test-tall.png`：縦長（3:4）の透過PNGの相棒
- `food/test-wide.svg`：横長（8:5）のおにぎり弁当

設定ファイルで `pet.base` と `food.onigiri` の `src` と `aspect` をこれらに向けると、縦横比が違っても崩れないこと、名前や所持数が変わらないこと、タップや食事の反応が動くことを確認できます（この確認は実施済みで、確認後は元の設定に戻しています）。

## 10. 仮素材について

`public/assets/` の中の絵は、すべてこのMVPのために作った**仮素材**です（SVGの図形だけで描いた簡易なもの）。
参考画像のキャラクターやロゴは使っていません。完成イラストに置きかえる前提のものです。

## 11. 手描き感（Illustrator の「ラフ」のような揺れ）

仮素材は、縁だけが細かく揺れる手描き感に加工しています（形そのものは崩さない）。
UI（アイコン・文字・ボタン・カード・ナビ）は加工せず、くっきりのままです。

### 仮素材の作り直し方

揺れは画像に焼き込んであります（実行時のフィルターではないので、Figma でも同じ見た目になり、動いても縁がちらつきません）。

- 元データ：`scripts/art-src/`（揺らす前のきれいな形の SVG）
- 出力先：`public/assets/`（同じ名前で上書き。`assets.config.ts` は変えない）

```bash
npm run art:rough                          # すべて作り直す
npm run art:rough -- food/onigiri.svg      # 1枚だけ作り直す
npm run art:rough -- --amp 2.2             # 揺れを強くする（表示サイズでの px）
npm run art:rough -- --amp 1 --seed 7      # 弱めに・別の揺れ方で
```

- 揺れの強さは **表示サイズで 1.6px**（最大値の目安）、点の間隔は 3px、種は 1 です
- 揺れは「実際に表示される大きさ」を基準にしています。表示の大きさは `scripts/roughen.mjs` の `DISPLAY` の表で決めています
- 目・海苔・きらきらなどの小さい部品は、大きさに応じて揺れを弱めています。とても小さい点（目の光）は揺らしません
- 揺らしたくない図形には、元データの SVG で `data-rough="off"` を付けます（例：背景の壁）
- 部屋の背景は、壁と床の境目だけが揺れるようにしています

### 自分で描くときの目安（Illustrator）

「効果 → パスの変形 → ラフ」を、次のくらいで小さめにかけると、仮素材と同じテイストになります。

| 項目 | 目安 |
|---|---|
| サイズ | 「入力値」で、表示サイズの横幅の約1%（例：表示160pxの相棒なら 1.6px） |
| 詳細 | 表示サイズで描く場合 8〜12／inch、2倍で描く場合 4〜6／inch |
| ポイント | 「丸く」（ギザギザの「直線的」にはしない） |

- 縁がガタガタしすぎて「毛羽立って」見えたら、詳細を下げます
- 形がいびつになりすぎたら、サイズを下げます
- 目や口などの小さい部品には、ラフをかけないか、半分以下にします
